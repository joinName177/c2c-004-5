# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高与承重配置
- 物品清单、类别、尺寸、重量、优先级和必带标记
- 确定性三维长方体装箱、旋转与碰撞检测
- 三套方案对比和双投影视图联动
- 超重、空间紧张、尺寸越界、必需品遗漏、易碎品受压和重心风险
- 出发前实际装箱核对：逐项记录待准备/已放入/临时取出，必带遗漏阻止宣布完成
- 物品或方案变更后按物品身份复核核对进度，未变项保留、变更项重新确认
- localStorage 本地保存（含核对进度）与打印清单

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

## 出发前核对

方案可行不等于已经装箱。确认方案后可开始出发前核对：每件物品记录“待准备 / 已放入 / 临时取出”，只有当前方案装入的物品才能记为已放入；存在必带物品未放入时无法宣布全部完成。核对期间修改尺寸、增删物品或切换方案时，系统按物品身份逐项复核——尺寸或摆放位置变化的物品必须重新确认，未变物品保留状态，删除的物品从核对中移除。核对进度随快照持久化，刷新后继续进行；清单、摆放图与打印单同步显示规划位置与实际核对状态。

## 开发与测试

```bash
npm install
npm run dev
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

## Docker

```bash
docker compose up --build
```

访问 [http://localhost:8104](http://localhost:8104)。生产镜像由 Node 20 构建并由 Nginx 1.27 托管，已配置单页应用回退。
